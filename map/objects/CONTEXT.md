# objects/ — the nouns

One card per durable thing an editor asks about: a table or a module. Clustered by how Billy
asks ("a note", "a person", "a vehicle", "the email drip"), not by folder layout.

- **Reads:** `_index.md` first. Follow the source path on a stub; open the card on a verified line.
- **Writes:** a new card = copy `../_templates/object.md` into `<cluster>/<slug>.md`, fill every
  section, cite `path:line`, then flip the index line to `[x] … verified`. Shared nouns get `shared: true`.
- **Human check:** Billy reads the Hits / Does not hit of any card before it is called verified.
  A wrong waterfall costs more than a missing card — doubly so on the shared tables.

Slice 1 state: index only, no cards, no cluster folders.
